# Cloneable React Template Repository
This repo is meant to be a starter react app to reduce redundancy in builds.

## Integrations
- React Router
  - Includes 404 routing
- Error page with different error codes for various scenarios
##
- Google Firestore Database
  - Ghost routes and functions without actual database connection
- Google Firebase Authentication
  - Login page
  - Profile Dashboard Page
 
## Modules
- Color Picker
- Progress Bar
- Slate Text editor
- Linear Graph
- Histogram Chart
- Pie Chart
