# Cloneable React Template Repository
This repo is meant to be a starter react app to reduce redundancy in builds.

## Features
- React Router
  - Includes 404 routing
- Error page with different error codes for various scenarios
- Navigation Menu (Mobile and Widescreen)
  - Includes dropdown menus and transitions
  - Fully implemented with CSS, can be applied to plain HTML pages
 
## In Progress Integrations
- Color Picker Module

## Future Additions
- Slate Text Editor
- Database Integration Layout
  - Ghost routes and functions without actual database connection
